Task 1 – Simple Storage Smart Contract

Objective

To develop a basic Solidity smart contract that demonstrates how blockchain data is stored and managed.

Features

- Store a single integer value.
- Set and update the stored value.
- Increment and decrement the value.
- Retrieve the stored value.
- Emit events when the value changes.
- Validate input to prevent negative values.

Technology Used

- Solidity
- Remix IDE
- Ethereum Virtual Machine (Remix VM)

Testing

The smart contract was compiled, deployed and tested using Remix IDE.

Expected Output

- setValue(10) → 10
- increment() → 11
- decrement() → 10
- updateValue(25) → 25
