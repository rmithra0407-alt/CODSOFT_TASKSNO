Task 2 – Student Certificate Verification

Objective

To develop a blockchain-based certificate verification system using Solidity.

Features

- Store student certificate details.
- Store student name, certificate ID, course name and issue date.
- Verify certificates using a unique certificate ID.
- Prevent duplicate certificate IDs.
- Allow only the contract owner to add certificates.

Technology Used

- Solidity
- Remix IDE
- Ethereum Virtual Machine (Remix VM)

Testing

The smart contract is compiled, deployed and tested using Remix IDE.
