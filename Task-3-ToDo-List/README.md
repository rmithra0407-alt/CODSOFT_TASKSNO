Objective

To develop a decentralized task management application using Solidity that stores user tasks securely on the blockchain.

Features

- Add new tasks with task descriptions.
- Update task status as completed or pending.
- Retrieve all tasks associated with a specific wallet address.
- Store task creation timestamps.
- Organize tasks using mappings and structures.
- Allow users to delete completed tasks.
- Emit events for task creation and completion.

Technology Used

- Solidity
- Remix IDE
- Ethereum Virtual Machine (Remix VM)

Testing

The smart contract is compiled, deployed and tested using Remix IDE.

The following functions are tested:

- Add Task
- Update Task Status
- Get Tasks
- Get Task Count
- Delete Completed Task
